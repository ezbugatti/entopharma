# entopharma.mn — Энто Фарм ХХК танилцуулга сайт

ЭНТО ГРУПП-ийн охин компани **Энто Фарм ХХК** (20 салбар сүлжээ эмийн сан)-ийн танилцуулга вэб.

## Дизайн

[ento.mn](https://ento.mn)-тэй (`entollc` репо) нэг гэр бүлийн, гэхдээ эмийн сангийн өөрийн дүр төрхтэй:

| | ento.mn (групп) | entopharma.mn (эмийн сан) |
| --- | --- | --- |
| Ижил | brand teal `#00AC94`, Inter үндсэн фонт, лотус лого | ← |
| Дэвсгэр | хүйтэн саарал `#F9FAFB` | дулаан цөцгий `#F6F3EC` + гүн нарсан ногоон `#0E2F2A` |
| Гарчиг | Inter semibold | Manrope extrabold (Ө, Ү бүрэн дэмждэг) |
| Товч | `rounded-lg` | капсул `rounded-full` |
| Чимэглэл | бүдэг ногоон blur | эмийн сангийн «+» загалмай, нуман (apothecary) зураг, шар accent |
| Hero | төвд текст | зүүн талд салбар хайлт, баруун талд нуман зураг + «Яг одоо X салбар нээлттэй» |

Токенууд: `app/globals.css` (`@theme`). Загалмай: `components/ui/Cross.tsx`.

## Ажиллуулах

```bash
npm install
cp .env.example .env.local
npm run dev        # http://localhost:3000
npm run build && npm start
```

## Салбарын өгөгдөл

- ento.mn-тэй **ижил Sanity project**-оос `type->value == "pharmacy"` салбаруудыг татна (`lib/branches.ts`, 1 цаг тутам шинэчилнэ).
  Sanity Studio (ento.mn/studio) дээр салбар нэмэх/засахад энэ сайт автоматаар шинэчлэгдэнэ.
- Sanity холбогдохгүй бол `lib/branches.fallback.ts` (2026-10-19-ний хуулбар) ашиглана.
- «Нээлттэй/Хаалттай» төлвийг `schedule` текстээс Улаанбаатарын цагаар тооцно (`lib/schedule.ts`).
  Шинэ формат нэмбэл тэнд regex-ийг өргөтгөнө.
- Дүүргийг хаягаас тодорхойлно (`lib/district.ts`). Хаягт дүүрэг заагаагүй салбарыг `NAME_OVERRIDES`-д нэмнэ.

## Солих / шалгах шаардлагатай зүйлс

- **Лого** — эх файл `public/pharma-logo.png`. Солих бол энэ файлыг шинэчлээд `npm run logo` ажиллуулна (тайрсан өнгөт + цагаан хувилбар үүснэ).
- **Текст** — Ихэнх нь ento.mn-ийн Pharma/OurValues/About текстээс авсан; шинээр бичсэн хэсгүүдийг (hero, бүтээгдэхүүний ангилал, эм зүйчийн зөвлөгөө, эрхэм зорилго) маркетинг хянах.
- **Сошиал** — `lib/site.ts`: Facebook нь одоогоор ento.mn-ийн хуудас руу заасан.
- **Имэйл** — `.env.local`-д `EMAIL_*` тохируулахгүй бол форм 503 буцааж, утсаар холбогдохыг санал болгоно.
- **Зураг** — `npm run images -- ../entollc/public/images` ento.mn-ийн эх зургуудыг WebP болгож `public/images/`-д хийнэ.
